# Store Listing Draft

## Name

Bilibili MrBeastify

## Short Summary

Adds random MrBeast overlays to Bilibili thumbnails.

## Description

Bilibili MrBeastify makes Bilibili browsing more chaotic by adding random MrBeast overlays to thumbnail-like images across the site.

It supports Bilibili home feed cards, search results, video-page recommendations, live/video covers, banners, and dynamically loaded content. The popup lets you enable or disable the extension and adjust the overlay appear and flip chances.

This extension is unofficial and is not affiliated with Bilibili, YouTube, or MrBeast.

## Category

Fun / Entertainment

## Single Purpose

Modify Bilibili thumbnail-like images by adding local MrBeast overlay images.

## Data Use

The extension does not collect or transmit user data. It stores only local extension settings in browser local storage.

## Testing Instructions

1. Install the extension.
2. Visit `https://www.bilibili.com/`.
3. Confirm Bilibili thumbnails and carousel slides show MrBeast overlays.
4. Open the extension popup and toggle the extension off.
5. Refresh Bilibili and confirm overlays no longer appear.
