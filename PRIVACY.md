# Privacy Policy

Bilibili MrBeastify does not collect, sell, share, transmit, or remotely store user data.

The extension runs locally in the browser on Bilibili pages. It only reads the page DOM to find thumbnail-like images and adds local extension images as visual overlays.

The extension uses browser local storage only for user-controlled settings:

- Whether the extension is enabled.
- The overlay appear chance.
- The overlay flip chance.

These settings remain on the user's device and are not sent to the developer or any third party.

The extension does not use analytics, tracking pixels, remote logging, cookies, account systems, or external servers.
